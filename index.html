¿Qué datos recogemos y para qué?

Durante esta fase de pruebas técnica (Beta), nuestra aplicación utiliza herramientas de análisis (SDKs) para entender cómo funciona el software y mejorar su estabilidad. Los datos que recogemos son:

  • Identificadores técnicos: ID de publicidad limitado, ID de instancia de la app y dirección IP (anonimizada).
  • Datos de rendimiento: Informes de errores (crashes), tiempo de respuesta de las pantallas y funciones más utilizadas.
  • Finalidad: La base legal para este tratamiento es nuestro interés legítimo (Art. 6.1.f RGPD) para garantizar la seguridad, corregir errores técnicos antes del lanzamiento oficial y mejorar la experiencia de usuario.

Herramientas de Terceros
